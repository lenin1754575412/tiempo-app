# TIEMPO.APP — estilo iOS elegante

Proyecto Expo Router con tres herramientas: reloj en tiempo real, gestión de alarmas y cronómetro.

## Ejecutar
```powershell
npm install
npx expo start --clear --lan --port 8085
```

Si LAN no funciona: `npx expo start --clear --tunnel --port 8085`.

Las alarmas se administran dentro de la aplicación, sin notificaciones del sistema.
